¿Qué es el Modelo de Caja?

En CSS, el Modelo de Caja (Box Model) es el núcleo del diseño web. Cada elemento se comporta como una caja rectangular compuesta por cuatro capas: el contenido real, el espacio interno (padding), el borde (border) y el espacio externo (margin).

Propiedades Clave de CSS

Las propiedades de CSS controlan el aspecto visual. En este ejemplo hemos usado display: flex para alinear columnas, background-color para los fondos, y propiedades de texto como text-transform para dar formato profesional.
